# GitHub publication checklist

1. Create a **new public** GitHub repository named `ALIASTORM-STORM-REBORN` under your own account. Do not overwrite or modify `AliaStorm-Favorite`.
2. Keep the new repository **empty** on GitHub (do not initialize it with a README, license, or .gitignore). Extract this package, open a terminal **in its extracted folder**, and run `bash PUBLISH-TO-GITHUB.sh`. Type `PUBLISH` after reviewing the exact new repository URL. The helper stages only approved public files, artwork, source and tests. It does not touch any older repository or global Git settings.
3. The publishing helper sets local Git commit author to **Hellfire13666** with GitHub’s account-specific no-reply address. You may have to authenticate GitHub on your own computer during push. Never share a password or token in chat.
4. In GitHub: **Settings → Pages → Build and deployment → Deploy from a branch → main → /docs → Save**.
5. Wait for GitHub to report the page as published. Test `https://hellfire13666.github.io/ALIASTORM-STORM-REBORN/` in a private browser window.
6. Test X/Facebook previews after publishing. The Open Graph image is an absolute URL and may take some time to refresh.
7. Keep your local vault entirely off GitHub.
