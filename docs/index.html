🔐 The private vault

Use the included local vault helper to create an isolated report archive outside the repository. It does not upload your searches anywhere, and it does not move or delete your existing files.

  1. Run the tool locally.
  2. Keep reports in local local-reports/.
  3. Optionally back them up to a private GlitchByte vault on your machine.

☠️ Repository + installation

The GitHub repository holds the public source package, catalog attribution, artwork, launch script, and tests. Real scanning runs on your own Linux computer, not through this showcase page.

  1. Get the project files from the repository.
  2. Open the extracted project folder.
  3. Run bash RUN-ALIASTORM.sh --color always.

Public source observations are not proof that two accounts belong to the same individual. Do not publish private investigation reports or sensitive personal information in this repository.
